# prompt-engineering

Biblioteca reutilizável de prompts, templates e práticas para engenharia de software, coordenação de agentes de IA, revisão, auditoria e documentação.

## Estado de publicação

- Snapshot-base do projeto declarado pelo responsável: `v1.0.0`.
- A auditoria inicial foi documentada separadamente como relatório de Fase 1 `v1.0.1`; essa identificação não altera retroativamente o snapshot-base.
- A auditoria da Fase 2 foi encerrada com bloqueios de proveniência, licenciamento e prontidão; consulte `docs/PHASE-2-CLOSEOUT.md`.
- Este repositório documenta governança. **Não declara que todo o conteúdo da cópia local foi importado ou validado.**
- Nenhum segredo, token, credencial OAuth, arquivo `.env`, dado privado de identidade ou evidência sensível deve ser publicado.

## Regras de governança

1. O administrador humano mantém a autoridade final.
2. Agentes devem distinguir leitura, proposta, execução e publicação.
3. Mudanças destrutivas, alterações de permissões, autenticação e publicação de dados sensíveis exigem autorização explícita e específica.
4. Evidências devem registrar origem, ambiente, data, comando, resultado e limitações.
5. Não se deve afirmar que uma validação, autenticação, certificação ou teste foi concluído sem evidência verificável.
